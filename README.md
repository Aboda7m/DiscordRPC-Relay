# DiscordRPC-Relay

A lightweight Python-based relay for Discord Rich Presence (RPC) data, designed to bridge or forward presence updates between applications or services.

## Overview

DiscordRPC-Relay provides a simple way to forward Discord RPC activity data between clients, services, or local applications. It is useful for:

- relaying Rich Presence updates between apps
- exposing local RPC data to another process
- testing or integrating Discord presence into custom tools
- building small automation around Discord activity state

This project is intended for local or controlled environments and should be used responsibly.

## Features

- Python-based Discord RPC relay
- Easy setup and configuration
- Lightweight architecture
- Supports custom host/port configuration
- Simple logging and debugging
- Designed for extension or integration with other tools

## Requirements

- Python 3.9+
- pip
- Internet access for installing Python dependencies
- A valid Discord application/client setup if using Discord RPC features
